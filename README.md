# 求职工作台

面向 Windows 本机运行的简历素材管理与简历生成工具。

当前版本为 **0.1.0-test 公开预览版**，目标环境为 Windows 10/11 64 位和 Microsoft Edge，尚未进行代码签名，不宣称正式稳定版。

首次发布完成后，从 [官方 Releases 页面](https://github.com/yexu233-prog/career-workbench/releases) 下载 `career-workbench-0.1.0-test.zip` 和同名 `.zip.sha256`。GitHub 自动提供的 Source code 压缩包不是可双击程序。下载 ZIP 后核对 SHA-256，解压到独立目录再启动；详细步骤见 [Windows 使用说明](docs/Windows测试版使用说明.md)。

## 当前可用功能

- 独立个人资料模块与右上角照片上传、预览和删除；
- 七类简历素材、共享事实和可选专属字段；
- 素材字段的“进入简历 / 仅内部使用 / 用于 AI 参考”说明和虚构呈现示例；
- 从 DOCX、TXT 或文本型 PDF 手动整理素材，或主动调用 AI 拆分候选；
- 导入候选可新建素材或为同类别已有素材新增版本；差异经确认后留作内部备注，共享信息和已有简历不被覆盖；
- 原始版本、自定义岗位版本与面试备注卡；
- 自动保存、搜索筛选、复制和回收站；
- 长期保存的简历项目、独立素材快照和来源更新提示；
- 模块与条目编排、自由文本模块和项目内二次修改；
- 标准 A4 单栏分页预览与项目级排版设置；
- 标准单栏右上角照片位置提示，无照片时正式简历自动使用完整宽度；
- TXT、DOCX 和文本型 PDF 的 JD 本机解析与确认保存；
- 使用 Windows DPAPI 保护密钥的可选 AI 服务配置；
- 岗位分析、素材版本、面试备注、素材推荐和简历条目优化候选；
- PDF 与可编辑 Word 导出、导出前风险提示和最近导出时间；
- 完整备份、恢复、最近确认保存时间和 7 天非阻断提醒；
- 本机故障诊断与不含正文的诊断文件；
- 无需安装 Node.js 的独立 Windows 测试包；
- 数据仅保存在本机浏览器数据库中。

Windows 用户可双击 `启动求职工作台.cmd` 启动，双击 `停止求职工作台.cmd` 停止。
发布 ZIP 同目录提供 `.zip.sha256`；包内提供 `LICENSE`、`version.json`、`发行说明.md`、`manifest.json` 和 `licenses/`。项目源码采用 MIT，Copyright (c) 2026 叶许；第三方组件保留各自许可证。先核对文件来源和校验值，不要从来源不明的位置运行未签名包，也不要关闭系统安全防护。许可资料见 `docs/许可证核对记录.md`。

业务数据保存在本机；**主动使用 AI 时，所选内容会发送给你配置的服务商，并可能产生费用**。无需 AI 时可以手动完成整理和生成。见 [架构与隐私说明](docs/架构与隐私说明.md)。
