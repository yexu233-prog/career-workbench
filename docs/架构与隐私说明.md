# 架构与隐私说明

## 本机架构

React + TypeScript 页面通过 Node.js 本机服务运行，正式来源固定为 http://127.0.0.1:41823。IndexedDB/Dexie 保存业务记录；支持 Windows 或 Mac 当前用户使用，不作为互联网或局域网共享服务器。Mac Safari / Chrome 的业务数据独立，切换需通过完整备份迁移；Intel 包为实验性、未完成实机验证。

业务功能为素材管理和简历生成。个人资料、导入、设置和回收站是辅助页面。素材版本、项目快照、回收站、完整备份及修订检查保护编辑流程；恢复会整体替换数据，需要先备份并确认。

预览与 PDF 使用统一文档模型和标准 A4 单栏模板；Word 使用可编辑 DOCX。Word 中后续修改不会自动回写应用。

## 文件和密钥

Edge 资料位于 `%LOCALAPPDATA%\求职工作台\browser-profile`，API 密钥由 Windows DPAPI 保护并存于同用户的 `secrets` 目录。不要手工迁移或修改这些目录。业务记录和密钥不随发布 ZIP 分发。

Mac 业务数据位于所选 Safari / Chrome 的 IndexedDB；启动偏好和运行记录位于当前用户 `Library/Application Support/求职工作台`。API 密钥由隔离辅助进程通过 Koffi 访问当前用户的文件型本机钥匙串，不选择 iCloud 同步后端，不回退到明文配置。系统授权主体是随包 Node，不是 JavaScript 应用的独占身份，不抵御已控制当前用户账户或程序文件的恶意代码。调用时密钥仍短暂进入内存；升级或移动程序可能再次提示授权。

Mac PDF 使用随包匹配架构的 Chrome Headless Shell，与界面使用 Safari / Chrome 无关，不要求 Edge。运行组件和字体在包内，不要求首次启动下载或安装开发工具。公开预览包未 Developer ID 签名、未 Apple 公证；完整性哈希不是签名替代品。

完整备份是可读 JSON，包含资料、照片和简历业务内容，可能含敏感信息；它不是加密档案，请安全保管且不要上传到 Issues 或公开仓库。密钥、AI 候选和临时会话不包含在完整备份中。

## AI 请求

只有用户主动调用时，本机服务才向已配置接口发请求。发送范围依任务而异，包括所选经历、素材、项目内容或 JD；结果先作为候选，经确认后写入业务数据。本机存储并不阻止这些主动的网络传输。

用户应核对服务商、接口地址、模型权限、费用和隐私条款；厂商接口兼容不等于全部模型已验证。自定义地址接收你配置的密钥和所选内容，应只使用可信地址。

本产品不内置遥测或第三方分析 SDK。日志及故障诊断不应包含正文和密钥；反馈前仍应人工检查截图及附件。
