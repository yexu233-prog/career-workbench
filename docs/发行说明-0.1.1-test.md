# 求职工作台 0.1.1-test 公开预览版

## 更新

- 修复 PDF 简历和岗位 JD 导入失败：PDF.js 解析线程与应用线程协议分离，中文字形映射及基础字体随包提供，无需外部 CDN。保留候选确认、取消/超时、损坏及密码文件提示；不增加 OCR。
- 提供 Windows 64 位、Apple Silicon Mac 和 Intel Mac 三套独立 ZIP。Mac 无需 Node、Git、Homebrew 或 Xcode，启动时选择 Safari / Chrome；PDF 使用随包引擎。
- Mac AI 配置使用当前用户文件型本机钥匙串，不选择 iCloud 同步后端、不明文回退、不写入浏览器库或业务备份。Windows 继续使用 DPAPI。
- 保留两个业务模块、标准 A4 单栏模板、PDF/可编辑 Word、回收站、完整备份和主动 AI 候选确认。

## 下载、升级与回退

下载对应架构 ZIP 和同名 `.zip.sha256`，核对哈希后解压。Source code 压缩包不是可双击产品。Windows 使用 `.cmd`，Mac 使用 `.command`；保留完整目录。

旧版仍能打开时，先保存完整业务备份，再停止旧版；新版解压到独立目录，检查资料、编辑、重启及导出，保留旧包与升级前备份。当前数据库仍为 v1，无数据迁移；不兼容数据库不能强行用旧版写入。详细操作见随包 `使用说明.md`。

Safari 与 Chrome 的业务数据相互独立，通过完整备份迁移；目标已有资料时先备份。Windows/Mac 间不迁移 API Key，需要在目标系统自行配置。
