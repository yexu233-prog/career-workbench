## 安全与发行限制

用户确认本轮不推进 Developer ID 签名或 Apple 公证。不要求关闭 Gatekeeper/SIP，不批量清除隔离属性。SHA-256、文件清单及来源检查不是代码签名的替代品。

Mac API Key 使用当前用户文件型本机钥匙串，不选择 iCloud 同步后端，也不回退到明文文件。系统授权主体是随包 Node，不是 JavaScript 的独占权限边界。备份不含 API Key；Safari/Chrome 的业务数据库独立，迁移前备份目标资料。

用户可使用 `运行自检.command` 核对下载后的包并反馈报告。具体步骤见[Mac 使用说明](Mac测试版使用说明.md)。
