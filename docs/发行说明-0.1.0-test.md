## 本版主要能力

- 公开发布准备已更新本机服务、网络请求、XML 导入解析及相关依赖的安全补丁，并增加干净提交／标签检查和 Windows 自动测试；AI 不在自动测试中真实付费调用。

- 在本机管理个人资料、简历素材、经历内容、素材版本、面试备注和可反复编辑的简历项目。
- 提供标准 A4 单栏简历预览，以及 PDF、可编辑 Word 文件导出。
- 支持主动触发 AI 候选、检查后采纳；支持 OpenAI、通义千问、DeepSeek、智谱 GLM 和自定义兼容接口。
- 提供完整备份与恢复、回收站、数据库迁移前安全快照，以及备份时间提醒。
- 修复本机数据库暂时无法打开后，“重新尝试”无法恢复的问题；存储空间不足时保留未保存的编辑内容。

## 升级和回退

1. 旧版仍可使用时，先在设置页导出并确认保存完整备份。
2. 停止旧版，把本包解压到新目录；不要覆盖旧版目录。启动后检查资料、素材、项目和导出。
3. 保留旧包及升级前备份。若数据库结构不兼容，不要强行用旧版打开升级后的数据。

详细步骤见随包 `使用说明.md`。业务数据存放于当前 Windows 账户的独立 Edge 资料目录，不包含在 ZIP 中。

## 已知限制和验收状态

- 仅提供标准 A4 单栏模板；不提供账号、云同步、OCR、机会管理、学习计划或自动 AI 调用。
- AI 厂商接口可尝试连接，不代表任意模型已通过全部简历任务验证；实际调用需用户自行配置密钥和额度。
- 本包为未签名的 Windows 公开预览版；应从官方 GitHub Release 下载。ZIP 校验和及逐文件清单用于完整性检查，不证明发布者身份。

- 已采用携带完整 BSD-2-Clause 原文的 dingbat-to-unicode 1.0.2；全部 1,061 条字符映射与旧版一致。当前收录的生产依赖许可原文缺口已补齐，不代表法律审查完成。
