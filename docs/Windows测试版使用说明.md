# 求职工作台 Windows 测试版使用说明

本说明适用于 `career-workbench-0.1.0-test` Windows 公开预览包。目标环境为 Windows 10/11 64 位和 Microsoft Edge。程序只在当前 Windows 账户的电脑上运行，内置 Node.js；简历数据不会随 ZIP 一起移动。本包尚未进行 Windows 代码签名，不宣称正式稳定版。

## 启动、停止与数据位置

1. 解压 ZIP 到一个独立文件夹，不要直接在 ZIP 压缩视图中运行。
2. 双击 `启动求职工作台.cmd`。应用会启动本机服务，并在 Microsoft Edge 中打开 `http://127.0.0.1:41823`。
3. 用完后双击同一文件夹中的 `停止求职工作台.cmd`。关闭 Edge 窗口并不等于停止本机服务。

简历素材、项目和设置保存在当前 Windows 账户的 Edge 专用资料中，位置为 `%LOCALAPPDATA%\求职工作台\browser-profile`；AI 密钥由本机服务使用 Windows DPAPI 保存在 `%LOCALAPPDATA%\求职工作台\secrets`。请勿手工移动、清理或改写这些目录。删除程序文件夹不会自动删除上述数据，但这些目录不能代替应用内的完整备份。

## AI 服务与完整备份

- 打开“设置 → AI 服务”，选择服务商，填写该服务商的接口地址、模型 ID 和 API Key，保存后点击“测试已保存配置”。只有主动点击 AI 功能才会发送所选内容。密钥不进入简历备份。
- 打开“设置 → 数据备份与恢复”，点击“导出完整备份”。若出现文件保存窗口，以完成保存为准；若浏览器直接下载，请在下载文件夹找到 JSON 文件，再点击页面上的“我已确认备份文件保存”。
- 设置页显示最近确认保存的备份时间。尚未记录备份或距上次已满 7 天时会提醒，提醒不会阻止继续使用。
- 恢复会整体替换当前简历数据。先保存当前数据的新备份，再选择备份文件、检查摘要并确认恢复。请将 JSON 文件保存在程序文件夹之外的安全位置。

## 升级与回退

1. 在**旧版仍运行时**先从设置页导出完整备份，并确认 JSON 文件已保存。备份需要通过旧版页面完成，因此不能先停止旧服务。
2. 双击旧包的 `停止求职工作台.cmd`，确认旧窗口已不再提供服务。保留旧包及升级前备份，不要覆盖旧包目录。
3. 将新版 ZIP 解压到**另一个**目录。双击新版 `启动求职工作台.cmd`，检查个人资料、素材、简历项目和 PDF/Word 导出。
4. 若新版有问题，先停止新版。只有在确认新旧数据库结构兼容时，才从保留的旧包启动并继续编辑；如果数据库结构已升级或旧版提示不兼容，不要强行打开旧版或删除浏览器数据。保留升级前 JSON 备份，使用与该备份兼容的版本恢复，必要时暂停操作并寻求协助。

## 校验来源与常见故障

首次发布完成后，从 https://github.com/yexu233-prog/career-workbench/releases 下载可运行 ZIP 和 `.zip.sha256`，不要使用页面自动提供的 Source code 压缩包启动。解压前可在 PowerShell 中运行：

```powershell
Get-FileHash -LiteralPath '.\career-workbench-0.1.0-test.zip' -Algorithm SHA256
```

将输出与同一 Release 的 `.zip.sha256` 中的值对照。不一致时不要使用该 ZIP，应重新从官方 Release 取得文件。校验和用于检查文件一致性，不能证明发布者身份，也不能代替代码签名。若 Windows 对未签名文件显示安全提醒，先核对仓库来源和校验值；来源不明时不要运行，不需要关闭系统安全防护。

解压后的 `version.json` 记录构建时间、Git 提交、数据库与模板版本和随包 Node.js 版本；`发行说明.md` 列出本版变化与已知限制；`manifest.json` 是逐文件大小及 SHA-256 清单；`licenses/README.md` 汇总字体、Node.js 和第三方依赖的许可证资料。本项目源码采用 MIT，著作权人为叶许，原文见包根目录 `LICENSE`，不改变第三方组件许可。文件清单不包含自身，完整 ZIP 仍以上述 `.zip.sha256` 为准。公开发布前需核对许可证目录中标出的缺失原文。

| 现象 | 建议操作 |
| --- | --- |
| 只打开命令窗口或找不到 Edge | 阅读窗口中的中文错误；安装或修复 Microsoft Edge，或重新完整解压测试包。 |
| 提示其他版本已运行或 41823 端口被占用 | 先用正在运行版本的停止脚本停止服务，再启动目标版本；不要强制结束不明进程。 |
| 页面显示本机服务未连接 | 使用当前包的启动脚本重新启动；不要同时运行两个版本。 |
| AI 配置或连接失败 | 核对服务商、接口地址、模型 ID、密钥、网络和账户额度；手动编辑仍可继续。 |
| PDF 无法生成 | 在设置页运行“故障诊断”；确认 Edge 可用，再重试。 |
| 本机数据或自动保存失败 | 保留当前页面和未保存内容，检查磁盘空间与当前 Windows 账户；不要清除 Edge 资料或业务数据库。 |

设置页“故障诊断”可检查本机服务、浏览器数据库、存储配额、PDF 和字体，并导出不含简历正文的诊断文件。报告问题时不要附上真实简历、API Key 或个人备份。
