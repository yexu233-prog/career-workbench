# Bundled fallback font

- File: `NotoSansCJKsc-Regular.otf`
- Family: Noto Sans CJK Simplified Chinese
- Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
- License: SIL Open Font License 1.1; see `OFL.txt`

The Windows test build uses Microsoft YaHei first for exact PDF text mapping and this font only as an offline fallback. It is not stored in IndexedDB or user backups.
